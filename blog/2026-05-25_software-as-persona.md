# LLM 正在把软件从功能集合变成人格化接口

Hook：软件的终局可能不是菜单，而是关系。

我们过去理解软件，习惯把它看成一组功能的排列。按钮、页面、导航、表单、权限、模块，用户要学会它的结构，才能换来它的能力。这种设计哲学默认了一件事：机器不会主动理解人，所以人必须先学习机器。可 LLM 的出现，正在把这层关系倒过来。

当软件开始能够听懂自然语言、记住上下文、理解偏好、调整表达方式，它就不再只是一个功能仓库，而更像一个持续与你交互的接口人格。用户不必先研究菜单树，再猜哪个入口藏着哪个能力，而是直接从意图出发，让系统去匹配功能、组合流程、组织输出。软件从被操作对象，慢慢变成可协商对象。

这不是简单的聊天框加皮肤，而是产品逻辑的迁移。功能当然还在，但它们越来越退到后台。前台更重要的是这个系统如何理解我，是否可靠，是否记得我，是否能和我形成稳定合作关系。未来很多软件的差异，不在功能是否存在，而在它的“人格化接口”是否让用户愿意长期把上下文交给它。

也因此，产品竞争会出现一种新的分层。过去拼功能完备度，未来会越来越拼关系粘性。谁能让用户感觉自己不是在使用一台机器，而是在调用一个持续成长的外部认知器官，谁就更可能赢。菜单会被同质化，关系感不会。

当软件开始拥有接口人格，产品设计就不只是界面设计，而是合作体验设计。
