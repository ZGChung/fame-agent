# Jayson's Knowledge Base

## 写作风格
- 喜欢用「类比」和「反常识」来传达观点
- 典型句式：把复杂概念用简单比喻说清楚
- 不写学院派论文风格 — 写给人看的，不是给审稿人看的
- 常用结构：hook → 问题 → 分析 → 观点 → 行动建议

## 核心价值观
- AI 时代的核心竞争力不是技能，是判断力和元认知
- "做选择"比"做任务"更有价值
- 规模化能力 > 个人能力
- Agent-first 思维

## 常用术语
- Agent / Multi-agent
- AI Native
- Pipeline / 管道化
- 规模化能力
- 元认知
- 决策权重
- 知识搬运 vs 知识创造
- 信息差

## 语气偏好
- 不要装逼，不要爹味
- 可以有锋芒但不能刻薄
- 自信但不 arrogant
- 分享洞察不是布道
- 可以自嘲但不能自贬

## 受众画像
- AI 从业者、创业者、技术管理者
- 对 AI 趋势感兴趣的知识工作者
- 25-45 岁，有一定认知基础
- 不需要解释基础概念，但也不能过于技术化
