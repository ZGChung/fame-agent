# Twitter/X 审核标准

## 风格要求
- **语气**：简洁、有力、有洞察力。一句话要能让人停下来
- **长度**：≤ 280 字，长内容用 thread
- **风格**：观点鲜明，不怕引发讨论

## 内容要求
- 每条 tweet 要有一个明确的 punchline
- Thread 结构：hook → 展开 → 证据 → 结论 → CTA
- 适合的内容：
  - 反常识观点
  - 实时观察/反应
  - 短平快的经验分享
  - 引发讨论的问题

## 格式要求
- 使用 line breaks 增强可读性
- 适当使用 emoji（1-2 个）
- Hashtag 1-2 个即可

## 避坑
- 不要 thread 过长（超过 10 条要考虑 blog）
- 不要过度使用 hashtag
- 避免人身攻击
- 不要发纯链接无评论
